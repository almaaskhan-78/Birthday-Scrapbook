# 💌 Birthday Scrapbook

### A small interactive website made with a lot of love.

This project is a digital birthday scrapbook I created as a personal web-development project.

I wanted to turn a simple birthday message into something more interactive and memorable, so I designed a small website with different pages, transitions, and a scrapbook-inspired experience.

## ✨ Features

* 🔐 Birthday-based entry screen
* 💌 Interactive welcome/message pages
* 📖 Multi-page scrapbook experience
* 🎨 Custom visual design
* 🌸 Personal illustrations and assets
* 💻 Designed and developed as a web project

## 🛠️ Built With

* HTML
* CSS
* JavaScript

## 🎯 Why I Built It

This project was one of my early experiments with creating something from scratch and learning how different web pages, styling, and interactions work together.

It helped me practice turning a creative idea into an actual working website.

## 🌱 What I Learned

* Creating and connecting multiple HTML pages
* Styling pages with CSS
* Adding interactions with JavaScript
* Organizing website assets
* Debugging a multi-page project
* Designing a website around a specific visual concept
